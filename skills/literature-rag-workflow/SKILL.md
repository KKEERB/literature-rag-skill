# 文献 RAG 与精选精读

以用户提供或授权的本地原 PDF 建立用户自己的知识库，完成两轮处理、来源检索、精选精读和条目级人工审阅。首版不包含 Zotero 接入。先确认目标工作区与依赖状态；源码、论文、数据库、模型分析、人工审阅和科研结论是不同层次。使用本 skill 不等于授权上传论文或共享数据。

当前内置的三个研究 profile 和精读训练模板面向太空物理；其他学科的完整精读与工作区自定义 profile 尚未支持或验收。

首版为试用版本；批量重建和书籍专用入口不属于当前范围。macOS 已用虚构材料检查核心流程；Windows 不在本版支持范围内，尚未进行真机验收。

## 初始化与模型设置

首次使用或用户要求调整设置时读取 [安装和配置](references/setup.md)。询问用户为第一轮分析和第二轮独立复核分别选择模型、思考深度；尽可能使用宿主当前提供的模型列表和支持的深度，不编造可用选项。两轮可以同一模型，但复核任务不继承第一轮对话历史。

设置写到用户选定的工作区，不改用户全局 Codex 配置；请求模型不可用、调度不支持显式参数或设置无效时，解释并停止，不能静默换模型。用户之后可说“查看文献处理模型设置”或“修改文献处理模型设置”。修改只影响新批次；每个已创建批次的设置和来源绑定保持不变。区分请求设置、模型自报和实际执行回执；没有可信回执时不要声称底层模型身份已核实。

## 处理与查询

首次运行先执行 `runtime/scripts/onboarding_doctor.py`，按目标系统和已授权目录检查依赖。不要把依赖存在等同端到端通过。所有输入、数据库、发布根、会话和锁必须指向用户自己的工作区。必要的预检器缺失或版本不符时停止；不跳过验证。

处理 PDF、索引查询、精读和审核时读取 [操作流程](references/operation.md)。生成工作单只是准备，不代表完成模型阅读。两轮分别对原文进行分析与独立复核，仅合格条目入库；保留缺项、引用位置和作者语气。精选精读由用户选择。本 skill 不包含全文翻译管线。条目的人审接受仅表示该条忠实于原文；拒绝及意见保留并在允许引用时显式呈现，不推广为整篇正确或科学机制已证实。

来源身份、页码、条件、作者推断和不确定性要保留。证据缺失时明确说明，不补造身份或引用。用户没有明确授权时不发送、上传、发布或外写其材料；本地数据库不表示 Codex 模型处理一定离线。按需阅读方法参考：[流程](references/method/workflow.md)、[切分](references/method/chunking.md)、[检索](references/method/retrieval.md)。
